## Description (4000 chars max)

**Canto is the native macOS editor for Claude Code projects.**

If you use Claude Code, you live in markdown files — CLAUDE.md, project memories, coding plans, session logs. Canto gives you a fast, beautiful, native Mac experience for editing, previewing, and managing all of them.

### FEATURES

**Live Markdown Editing**
Write with a native text editor on the left and see an instant live preview on the right. Bold, italic, headings, lists, tables, code blocks, quotes — all rendered beautifully as you type.

**Built for Claude Code**
Canto understands Claude project structure. Browse your memories by type (user, feedback, project, reference), inspect CLAUDE.md sections, and track coding sessions — all from a clean sidebar.

**Lightning Fast**
Optimized parser, debounced preview rendering, and native AppKit text editing. Canto stays responsive even with large markdown files.

**Everything You Expect**
- ⌘B / ⌘I for bold and italic
- Format toolbar for headings, lists, links, quotes, and code
- ⌘F find with match count
- ⌘S save, ⌘N new file, ⌘W close tab
- Auto-save while you type
- Dark mode support
- Drag-and-drop project folders

**Your Files, Your Control**
Canto works with your local filesystem. No cloud, no account, no telemetry. Open any folder, edit any markdown file, and Canto stays out of your way.
